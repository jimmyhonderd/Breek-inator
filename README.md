# Breek-inator

Breakout in "Vroeger was alles beter"-pixelstijl met een LEDJOCKEY-tintje.

**Speel / installeer:** https://jimmyhonderd.github.io/Breek-inator/

## Installeren op Android

1. Open de link hierboven in Chrome.
2. Tik op ⋮ (rechtsboven) → **App installeren**.
3. De app staat daarna tussen je apps, start schermvullend en werkt offline.

## Besturing

- Vinger slepen = paddle, tikken = bal lanceren / laser schieten.
- Pc: pijltjes of A/D, spatie, P = pauze.

## Wat erin zit

- 8 levels met VWAB-billboards, multicolor blokken, harde en stalen blokken.
- Power-ups: E (breed), M (multiball), L (laser), K (kleefbal), + (leven), S (slow).
- Combo-vermenigvuldiger, highscore op het toestel, schermvullend op telefoon en tablet.
